System Requirements

Odysseus runs in Docker by default. Here's what each OS needs to run it, plus a couple of platform-specific quirks worth knowing about up front.

Windows

  • Windows 10/11, 64-bit
  • WSL2 enabled — Docker Desktop uses it as the Linux backend
  • Virtualization enabled in BIOS/UEFI (Intel VT-x or AMD-V)
  • Docker Desktop installed and running
  • At least 4 GB RAM allocated to Docker (8 GB+ recommended)

macOS

  • Docker Desktop for Mac installed and running
  • Apple Silicon (M-series): Docker can't reach the Metal GPU, so local model serving runs on CPU only inside the container
  • At least 4 GB RAM allocated to Docker

Linux

  • Docker Engine plus the Compose plugin
  • Your user added to the docker group (or run with sudo)
  • NVIDIA Container Toolkit or ROCm for GPU passthrough (optional)

All platforms also need Git and about 800 MB of free disk space for the image and container data.
