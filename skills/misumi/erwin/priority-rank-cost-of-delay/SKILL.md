## When to Use
Use when sequencing several important tasks.
## Procedure
1. Estimate harm, opportunity loss, and dependency delay.
2. Separate reversible delay from compounding delay.
3. Rank and state the decisive factor.
## Pitfalls
- Do not use urgency language as evidence.
## Verification
- Each rank has an explicit cost-of-delay reason.
