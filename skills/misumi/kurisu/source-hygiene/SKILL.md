## When to Use
Use when answering from files or external references.
## Procedure
1. Identify the canonical source.
2. Cite path and line or stable URL.
3. State absence or conflict directly.
## Pitfalls
- Do not cite a cache when canonical data exists.
## Verification
- Each material claim is traceable.
