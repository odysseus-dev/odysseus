# Учётные записи электронной почты Outlook / Office 365

Учётные записи электронной почты Odysseus в настоящее время используют IMAP и SMTP с аутентификацией по имени пользователя и паролю. Это работает для провайдеров, которые по-прежнему допускают пароли приложений или пароли почтовых ящиков для IMAP/SMTP.

Microsoft отключает базовую аутентификацию для Outlook и Microsoft 365 в большинстве современных учётных записей и арендаторов. Если вы попытаетесь добавить учётную запись Outlook с обычным паролем, Microsoft может вернуть ошибки, такие как:

- `IMAP: AUTHENTICATE failed`
- `SMTP: 535 5.7.139 Authentication unsuccessful, basic authentication is disabled`

Это ожидаемое поведение. Odysseus пока не поддерживает Microsoft OAuth или Graph Mail, поэтому учётные записи Outlook / Office 365 в настоящее время невозможно добавить через форму пароля. Используйте другой провайдер электронной почты с поддержкой паролей приложений или отслеживайте будущую интеграцию Microsoft Graph OAuth.
