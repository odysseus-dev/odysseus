# Windows Desktop Launcher

macOS ships `build-macos-app.sh` (double-click `Odysseus.app`). Windows now has
parity: a GUI launcher with preflight checks, server control, and browser app mode.

**Contributed by Wykeve (VoidCat) - 2026.**

## Quick start

After the normal Windows setup (`launch-windows.ps1` once, or manual venv + `setup.py`):

```powershell
powershell -ExecutionPolicy Bypass -File .\build-windows-launcher.ps1
```

Double-click **Odysseus** on your Desktop. Or run `Odysseus.vbs` from the repo root.

## What you get

- **Status panel** - Python, venv, dependencies, data dir, ChromaDB, Git Bash, Node, server
- **Setup** - create venv, `pip install`, `setup.py` (safe to re-run)
- **Launch** - start uvicorn, wait for `/api/health`, open Chrome/Edge app window
- **Stop / Open / Logs** - predictable log paths under `logs/`

| Log | Purpose |
|-----|---------|
| `logs/launcher.log` | Launcher actions and check results |
| `logs/odysseus-server.log` | uvicorn stdout/stderr |

## Preflight vs runtime

**Preflight** (before launch): required checks block **Launch** when failed. Optional
checks (ChromaDB, Git Bash, Node) show warnings but do not block.

**Runtime** (after start): server row tracks port, health, and readiness (`/api/ready`).

## Plugins

Drop a `.ps1` in `launcher/plugins/` to add checks. Contract: `launcher/plugins/PLUGIN.md`.

Filename order + `Order` field control sort. Use `Required = $false` for advisory checks.

## Paths with spaces

Repo paths containing spaces (e.g. `The Great Library`) work. Prefer:

- Desktop shortcut from `build-windows-launcher.ps1`
- `Odysseus.vbs` (uses `PSScriptRoot`, no manual `cd`)

Avoid wrapping `launch-windows.ps1` in shells that break quoted `cd` paths.

## ChromaDB on native Windows

Without Docker, ChromaDB shows **warn** and vector memory/RAG run degraded. To enable:

```bash
docker compose up -d chromadb
```

Then restart Odysseus from the launcher.

## Files

```
Odysseus.vbs                  # double-click entry (no console flash)
build-windows-launcher.ps1    # Desktop shortcut + optional icon
launch-windows-app.ps1        # opens GUI from a terminal
launcher/
  Odysseus.Launcher.ps1       # WinForms GUI
  lib/                        # server, browser, plugin host, env helpers
  plugins/                    # preflight/runtime checks (extensible)
  assets/odysseus.ico         # generated by build script (optional)
```
