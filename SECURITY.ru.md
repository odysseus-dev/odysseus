# Политика безопасности

Odysseus — это self-hosted AI-рабочее пространство с привилегированными локальными возможностями. Пожалуйста, не запускайте его как публичный сервис без аутентификации.

## Поддерживаемые версии

Исправления безопасности вносятся в основную ветку, пока не начнут выпускаться формальные релизы.

## Рекомендации по развёртыванию

- Держите `AUTH_ENABLED=true` для любого развёртывания, доступного по сети.
- Держите `LOCALHOST_BYPASS=false` вне локальной разработки.
- Выставляйте `SECURE_COOKIES=true`, когда Odysseus отдаётся по HTTPS через доверенный обратный прокси или приватный шлюз доступа.
- Используйте HTTPS при выставлении приложения за пределы localhost.
- Поставьте аутентифицированную точку входа веб/API Odysseus за доверенный обратный прокси или приватный слой доступа — такой как Cloudflare Access, Tailscale или VPN.
- Держите ChromaDB, SearXNG, ntfy, Ollama, vLLM, llama.cpp, базы данных и «сырые» API моделей/провайдеров только во внутренней сети.
- Защищайте `.env`, `data/`, `logs/`, загрузки, сгенерированные медиа, резервные копии, файлы авторизации/сессий, файлы баз данных, API-ключи и токены моделей/провайдеров.
- Отключите открытую регистрацию, если только вам осознанно не нужны новые учётные записи.
- Держите демо-/тестовых пользователей без прав администратора и полностью удаляйте их на серьёзных развёртываниях.
- Задавайте администраторским учётным записям надёжные пароли и включайте 2FA, где это возможно.
- Оставляйте высокорисковые инструменты агента доступными только администраторам: shell, Python, чтение/запись файлов, отправка/чтение почты, MCP, API приложения, управление задачами/навыками/памятью, настройки, токены и сервинг моделей.
- Ротируйте API-ключи, секреты вебхуков и API-токены Odysseus, если они появились в логах, скриншотах, демо или общих чатах.
- Относитесь к функциям shell, сервинга моделей, MCP, почты, календаря и vault как к привилегированной администраторской функциональности.
- Типичные порты только для внутренней сети: Odysseus `7000`, SearXNG `8080`, ntfy `8091`, ChromaDB `8100`, Ollama `11434` и локальные API моделей/провайдеров вроде `8000-8020`.

## Публикация форка

Перед пушем публичного форка выполните:

```bash
git status --short
git check-ignore -v .env data/auth.json data/app.db logs/compound.log odysseus.db
git grep -n -I -E "(sk-[A-Za-z0-9_-]{20,}|xox[baprs]-|AIza[0-9A-Za-z_-]{20,}|Bearer [A-Za-z0-9._~+/-]{20,})" -- . ':!static/lib/**' ':!package-lock.json'
```

Коммитить следует только `.env.example`, документацию, исходники, тесты и статические ассеты. Никогда не коммитьте действующие значения `.env`, содержимое `data/`, локальные базы данных, загруженные файлы, сгенерированные медиа, логи, резервные копии, файлы авторизации/сессий, API-ключи, токены моделей/провайдеров, хеши паролей или личные документы.

## Сообщение об уязвимостях

Пожалуйста, сообщайте об уязвимостях приватно через GitHub security advisories, если они доступны, либо открывая минимальный issue, не раскрывающий детали эксплойта.
